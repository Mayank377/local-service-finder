# 🚀 Local Service Finder

A full-stack web application for finding and managing local service professionals.

## Features

- User Registration
- User Login
- JWT Authentication
- Add Service
- Edit Service
- Delete Service
- Search Services
- MongoDB Database

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT
- bcryptjs

## Run Backend

```bash
cd backend
npm install
npm run dev
```

## Frontend

Open `lsf.html` using Live Server.
